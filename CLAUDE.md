# zijian-site: personal portfolio
Plain HTML/CSS plus a little vanilla JS. No frameworks, no build step.
Deploy: push to main, GitHub Actions publishes to GitHub Pages.

## Conventions
- Site files live in public/.
- Section ids: #hero #about #skills #projects #repos #contact.
- Keep it responsive; no horizontal scroll at 375px.

## Git and commits
- You may commit completed, relevant work to the current branch. Before each commit, review `git status` and the staged diff, run relevant tests, and stage only files belonging to your work.
- Concise commit messages. No AI attribution (no "Co-authored-by: Claude", "Generated by Claude", etc.).
- Use the repo's existing Git identity; never invent or change it. If it is missing or wrong, ask before committing.
- Do not push, merge, rewrite history, or switch branches unless asked.
